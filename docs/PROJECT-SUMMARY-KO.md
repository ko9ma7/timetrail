# TimeTrail 프로젝트 전체 정리

## 서비스 한 줄 정의

**지도를 클릭하고 시간을 움직이면 그 장소의 과거를 탐색하고, 인물·문명·전쟁·교역 경로를 Story Pack으로 따라가는 교육형 역사 지도 서비스.**

## 처음 제안된 핵심 아이디어

- 세계지도 + Time Slider
- 서울 1592, 부산 1592처럼 같은 연도의 지역 사건 탐색
- `What happened here 500 years ago?`
- `Follow a Person`: 마르코 폴로, 이순신 등 이동 경로를 따라 학습
- `Time Duel`: 서울 vs 런던처럼 같은 시대 두 도시 비교
- AI는 역사 사실을 발명하지 않고 **검증 가능한 자료를 이야기 구조로 정리**

## 현재 구현된 주요 기능

### 지도 탐색

MapLibre GL + OpenStreetMap 기반 세계지도. 지도 클릭 시 현재 선택 연도와 위치를 함께 고려해 가장 가까운 역사 기록을 찾습니다.

### 시간 탐색

기존 중세 중심 범위를 넘어 **기원전 3500년부터 2026년**까지 탐색할 수 있도록 확장했습니다. 기원전 표기는 `기원전 N년`으로 표시합니다.

### 사건 교육 카드

각 카드에는 가능한 범위에서 다음이 포함됩니다.

- 사건 요약
- 역사적 중요성
- 핵심 학습 포인트
- 관련 인물
- 관련 장소
- Wikipedia 대표 이미지와 개요
- 한국어/영문 Wikipedia
- Wikidata
- 나무위키 검색
- Wikimedia Commons 이미지 검색
- 자료 계층 / 좌표 정확도 / 검토 상태

- 마젤란-엘카노 세계일주
- 종교개혁
- 대서양 노예무역
- 미국혁명
- 라틴아메리카 독립

### Time Duel

24개 기본 도시를 이용해 같은 연도에 두 도시 주변의 가장 가까운 기록을 비교합니다.

### 즐겨찾기·테마

즐겨찾기와 테마 선택은 LocalStorage에 저장됩니다.

## 데이터 구조의 변화

초기에는 약 80개의 수동 사건만 있었습니다. 이 방식은 교육 깊이는 좋지만 세계 전체를 채우기 어렵습니다. 따라서 현재는 세 층으로 바뀌었습니다.

```text
교육 큐레이션 80+
        +
세계사 Backbone 200+
        +
Wikidata 자동 인덱스 최대 45,000
        ↓
     TimeTrail
```

기본 내장 데이터만으로도 네트워크 없이 주요 세계사 흐름을 볼 수 있고, GitHub Actions가 인터넷 환경에서 자동 인덱스를 주기적으로 늘릴 수 있습니다.

## 왜 Wikipedia/Wikidata 중심인가

TimeTrail의 원칙은 **LLM이 역사 사실을 새로 만들지 않는 것**입니다.

- 구조화 사실: Wikidata
- 상세 설명: Wikipedia
- 이미지: Wikipedia/Wikimedia Commons
- 한국어 추가 읽기: 나무위키 검색 링크도 제공
- AI/앱의 역할: 자료를 찾기 좋게 연결하고, 교육 순서와 비교 구조를 제공

## GitHub Pages 아키텍처

```text
GitHub Repository
├─ 정적 HTML/CSS/JS
├─ 교육 JSON
├─ Backbone JSON
├─ Wikidata 자동 Index
└─ GitHub Actions
      ├─ 정기 데이터 갱신
      └─ Pages 배포
```

별도 DB가 필요하지 않으며, 데이터 파일은 Git으로 버전 이력이 남습니다.

## Windows 원클릭 배포

`github-bootstrap.cmd` → `scripts/github-bootstrap.ps1` 구조로 동작합니다.

주요 단계:

1. 프로젝트 폴더 검사
2. Git/Node/npm/GitHub CLI 검사
3. GitHub 로그인 확인
4. 기존 `origin`/기존 repository 재사용 또는 연결
5. npm 검사·build
6. commit/push
7. GitHub Pages workflow 실행
8. 실제 Pages 배포 확인
9. 오류 로그 보존

이전 버전에서 발견된 Windows 배치 인코딩/CRLF 문제, PowerShell 배열 개수 검사 문제, 새 폴더에서 기존 GitHub repository의 `origin`이 없는 경우를 순차적으로 수정했습니다.

## 앞으로 확장하기 좋은 기능

- 연도별/지역별 데이터 파일 분할
- 인물 전용 데이터셋과 생애 경로 자동 생성
- 왕조·제국의 영토 변화 레이어
- 전쟁 전선/항로를 선(line)으로 표시
- 역사 지도(옛 국경) 오버레이
- 학교 교과과정별 Story Pack
- 사건 간 원인/결과 그래프
- 같은 연도의 세계 동시성 보기
- `현재 위치 50km / 100km` 역사 검색
- 퀴즈·복습 모드
- 교사용 수업 링크와 공유 가능한 URL state

## 유지보수의 핵심 원칙

**양은 자동 인덱스가 담당하고, 교육 품질은 큐레이션이 담당합니다.**

수집된 4만 건 모두에 긴 설명을 자동 생성하는 것보다, 좌표·날짜·출처가 정확한 넓은 인덱스를 만들고 중요한 사건부터 사람이 읽기 좋은 교육 카드로 승격시키는 방식이 TimeTrail에 가장 적합합니다.
