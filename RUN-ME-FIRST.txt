TimeTrail v1.2.1

1. Extract the ZIP completely. Do NOT run github-bootstrap.cmd inside the ZIP viewer.
2. Double-click github-bootstrap.cmd from the extracted project folder.
3. The bootstrap checks local curated + backbone + Story Pack data, Git/Node/npm/GitHub CLI, repository connection, build, push, Actions and Pages deployment.
4. On failure, the window remains open and github-bootstrap.log is written.
5. To generate the large Wikidata index after deployment:
   GitHub -> Actions -> Refresh historical data index -> Run workflow
   Default maximum: 45,000 records.
6. Korean data/coordinate guide: docs/DATA-GUIDE-KO.md
7. Full project summary: docs/PROJECT-SUMMARY-KO.md
